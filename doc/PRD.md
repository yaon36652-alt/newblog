## 1. 产品概述

### 1.1 项目名称

**MyBlog —— 个人博客系统**

### 1.2 项目目标

打造一个轻量、美观的个人博客平台，帮助博主高效地创作、管理与发布文章，同时为读者提供流畅的浏览体验。

- 博主可通过后台可视化地管理文章内容，无需技术背景即可完成发布、编辑、删除等操作。
- 读者可通过用户端方便地浏览文章、了解博主，获得良好的阅读体验。

### 1.3 核心价值

| 价值点 | 说明 |
| --- | --- |
| 内容沉淀 | 为博主提供长期的内容记录与展示平台，沉淀个人知识与思考 |
| 高效管理 | 后台提供文章统计与增删改查能力，让内容管理简单高效 |
| 品牌展示 | 通过「关于我」页面展示个人形象，建立博主个人品牌 |
| 优质阅读体验 | 多端适配（响应式设计），让读者在手机、平板、电脑上均可舒适阅读 |

---

## 2. 目标用户

| 用户角色 | 用户描述 | 核心诉求 |
| --- | --- | --- |
| 博主（管理员） | 博客系统的拥有者，负责内容的创作与管理 | 便捷地登录后台，快速发布/管理文章，了解博客整体数据情况 |
| 访客（读者） | 浏览博客的普通用户 | 快速找到感兴趣的文章，获得清晰舒适的阅读体验，了解博主本人 |

## 3. 功能需求

系统分为两个端：**用户端**（面向访客）与**博主管理后台**（面向管理员）。

### 3.1 用户端

#### 3.1.1 首页

**功能描述**

首页是博客的门面，向访客展示最新的文章列表，帮助访客快速发现内容并进入阅读。

- 展示文章列表，按发布时间倒序排列。
- 每篇文章展示标题、摘要、发布时间、分类/标签（如有）等信息。
- 支持点击文章卡片跳转至文章详情页。
- 导航栏提供首页、关于我等页面的入口。

**页面组件**

| 组件 | 说明 |
| --- | --- |
| 顶部导航栏 | 网站 Logo / 博客名称、导航菜单（首页、关于我） |
| 文章列表 | 文章卡片列表：标题、摘要、发布时间、阅读入口 |
| 分页 / 加载更多 | 文章数量较多时的分页或滚动加载 |
| 页脚 | 版权信息、备案信息（如有） |

#### 3.1.2 文章详情页

**功能描述**

展示单篇文章的完整内容，是访客阅读的核心页面。

- 展示文章标题、发布时间、完整正文内容。
- 正文支持富文本排版（标题层级、列表、代码块、图片等）。
- 提供返回首页的入口。

**页面组件**

| 组件 | 说明 |
| --- | --- |
| 顶部导航栏 | 与首页一致 |
| 文章标题 | 文章大标题 |
| 文章元信息 | 发布时间、分类/标签（如有） |
| 正文内容区 | 渲染富文本 / Markdown 正文 |
| 返回按钮 | 返回首页 |
| 页脚 | 与首页一致 |

#### 3.1.3 关于我页面

**功能描述**

展示博主个人介绍，帮助访客了解博主，建立信任与个人品牌。

- 展示博主自我介绍（头像、昵称、简介）。
- 可包含联系方式（邮箱、GitHub、社交媒体等）。
- 内容由博主在后台维护。

**页面组件**

| 组件 | 说明 |
| --- | --- |
| 顶部导航栏 | 与首页一致 |
| 博主头像 | 个人头像展示 |
| 个人简介 | 博主自我介绍文字 |
| 联系方式 | 邮箱 / 社交链接列表 |
| 页脚 | 与首页一致 |

---

### 3.2 博主管理后台

> 管理后台需登录后方可访问，未登录用户访问后台任何页面均跳转至登录页。

#### 3.2.1 管理员登录

**功能描述**

管理员身份校验入口，保证后台内容管理的安全性。

- 管理员通过账号和密码登录。
- 账号密码正确则跳转至后台仪表盘。
- 账号或密码错误时给出明确的错误提示。
- 支持退出登录。

**页面组件**

| 组件 | 说明 |
| --- | --- |
| 账号输入框 | 输入管理员账号 |
| 密码输入框 | 输入密码（密文显示） |
| 登录按钮 | 提交登录表单 |
| 错误提示 | 账号或密码错误时的提示信息 |
| 退出登录按钮 | 后台页面中的登出入口 |

#### 3.2.2 后台仪表盘

**功能描述**

登录后的默认页面，通过数据统计让博主快速了解博客整体状况。

- 展示文章统计：文章总数、最近发布文章数量等。
- 以卡片或图表形式呈现统计数据，一目了然。
- 提供进入文章管理的快捷入口。

**页面组件**

| 组件 | 说明 |
| --- | --- |
| 后台导航栏 | 仪表盘、文章管理等菜单 |
| 统计卡片 | 文章总数、本月新增、最近更新等统计指标 |
| 快捷入口 | 跳转至「新建文章」「文章管理」的按钮 |
| 退出登录 | 退出后台，返回登录页 |

#### 3.2.3 文章管理

**功能描述**

博主对文章进行全生命周期管理（增删改查）的核心模块。

- **查询（列表）**：以列表形式展示全部文章（标题、发布时间、状态），支持按标题搜索。
- **新增**：创建新文章，填写标题、摘要、正文内容后发布。
- **编辑（改）**：修改已发布文章的内容，保存后更新。
- **删除**：删除文章，删除前需二次确认，防止误操作。
- **查看**：从列表中快速跳转预览文章详情。

**页面组件**

| 组件 | 说明 |
| --- | --- |
| 文章列表 | 表格：标题、发布时间、操作按钮（编辑 / 删除 / 查看） |
| 搜索框 | 按标题关键字搜索文章 |
| 新建文章按钮 | 打开文章编辑表单 |
| 文章编辑表单 | 标题输入框、摘要输入框、正文编辑器、保存按钮 |
| 删除确认弹窗 | 删除前的二次确认提示 |

## 4. 非功能性需求

### 4.1 响应式设计

- 系统需适配 **桌面端、平板端、移动端** 三种主要设备尺寸。
- 用户端为响应式重点：移动端下导航栏可折叠，文章列表由多列变为单列，正文排版自动调整字号与间距，保证阅读舒适性。
- 管理后台同样需适配移动端，但以桌面端操作为主，移动端保证核心操作（查看、编辑）可用。

**适配标准**

| 设备类型 | 屏幕宽度范围 | 要求 |
| --- | --- | --- |
| 移动端 | < 768px | 单列布局，导航折叠，正文可舒适阅读 |
| 平板端 | 768px – 1024px | 自适应布局，内容区宽度合理 |
| 桌面端 | > 1024px | 完整布局，充分利用宽屏空间 |
